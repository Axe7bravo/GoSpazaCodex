Deferred variants: OFFER_EXPIRED_OR_NO_LONGER_AVAILABLE does not create another card; D/E will revalidate the original offer. Generic ORDER_CANCELLED/ordinary failed delivery have no proven shipped sources. PAYMENT_RECOVERY_ATTENTION needs a stable actionable episode rather than mutable provider_operation.reconciliation_pending; defer if no owner receipt proves it. NOTIFICATION_DELIVERY_ATTENTION mapping belongs with D's execution/ops audience, not a C retry/repair loop. No merchant/driver/platform EMAIL, earning-created notice, customer arrival email or extra message kinds.

Recipient identities and trusted route descriptors are frozen per source mapping admission in notification_mapping_audience to prevent a late-added member from receiving an old source on rediscovery; this is not a second intent dedupe authority. B's unique intent remains authoritative. The snapshot contains no address, message body or raw source payload. Contact binding is frozen on first actual intent creation; an existing intent is reused without retargeting after contact changes. Empty audiences fail closed; changing audience configuration does not silently backfill historic facts.

Source times are owning database transition timestamps read only after commit. They prove a lower bound on commit time; mappings never use worker arrival as source time. A transaction whose transition timestamp precedes activation but commits later cannot be proven eligible from that timestamp alone: fail closed and document that boundary rather than inventing a commit time. Normal postactivation transitions qualify through B's shared primitive. No source transaction or source schema is changed solely to make notification delivery succeed.
